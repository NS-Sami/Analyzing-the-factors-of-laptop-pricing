📘 Laptop Price Prediction
This project analyzes a dataset of laptop specifications and prices. The goal is to understand the relationship between features like CPU, RAM, screen size, weight, and the price of laptops. Basic data visualization and analysis techniques using Python are applied to gain insights.

📂 Dataset
Source: Kaggle

File Used: laptop_price.csv

Columns Include:

Company, Product, TypeName, Inches, ScreenResolution, CPU_Company, CPU_Type, CPU_Frequency (GHz), RAM (GB), Memory, GPU_Company, GPU_Type, OpSys, Weight (kg), Price (Euro)

🛠 Technologies Used
Python (pandas, matplotlib, seaborn)

Jupyter Notebook

GitHub

📊 Key Visualizations
Bar plot of laptop types

Pie chart of GPU companies

Line chart: CPU Frequency vs Price

Scatter plot: Weight vs Price

Box plot: Price by Company

Correlation heatmap of numeric features

✅ How to Run
Clone this repository or download the files.

Open the .ipynb file in Jupyter Notebook or VSCode.

Make sure the laptop_price.csv file is in the same directory.

Run the cells one by one to see the results.
